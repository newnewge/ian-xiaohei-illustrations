# Tony 动作总库（下次调用先读这份）

按主题取卡，不要一次全用。一张图只做一个动作。

调用口令：

```
Use $ian-xiaohei-illustrations
按 references/action-library.md 取动作。
主题：{品牌 / 颜色 / 说服 / 公众号 / 通用}
阶段：{路人 / 观众 / 判断者 / 立场者}（可选）
```

---

## 1. 通用库（内容生产系统）

搬运素材 / 拉线汇聚信息源 / 卡在断点里 / 拉动「判断」杆 / 变成筛选漏斗 / 切开「素材鱼」 / 盖章承接话术 / 牵着承接路径 / 举警告牌看坑 / 从洞里伸手但接不住 / 搬砖搭桥开门分拣记录 / 抱书讲解 / 举指示笔指板 / 举起识别面板

## 2. 公众号库

把痛点钉进靶心 / 在信息流河面抛开头钩 / 拧标题对比度旋钮 / 给长文开天窗 / 给封面套对焦框 / 盖原创火漆 / 踩定时发布踏板 / 给文章量完读体温 / 在评论池投喂 / 把单篇挂上专栏轨道

## 3. 品牌坏动作（优先，刻意的坏）

详卡：`brand-actions.md`

主库：把品牌按在镜子上逼问 / 给「我们不一样」翻吊牌 / 给空词举行加冕再当场摘冠 / 让口号当场自己念一遍 / 把承诺当空头支票剪开 / 在品类更衣室里掀门帘 / 给记忆点打一枚摘不掉的耳钉 / 把触点抓来排队认亲 / 开膖取出三句假话 / 抽走那把「什么都能坐」的椅子 / 把伸向脏活的手拍回去 / 让全部名字站成一排指认主犯 / 举起识别面板

增补：给「很有调性」做酒测 / 把抄来的视觉送去走失处 / 当众翻开品牌宝典只剩目录 / 给「深耕多年」查出生证明 / 让个人名和公司名办离婚 / 把「用户第一」夹上测谎仪 / 给爆款滤镜拆线 / 把定价当信号弹点着

禁止退回：焊接、刮漆、音叉、校色温、分层建楼。

## 4. 颜色开口

详卡：`color-actions.md`

| 想让用户…… | 指令 | 动作 |
|---|---|---|
| 注意、停一下、往这看 | 黄色说「瞄」 | 冷底上别一枚黄标 |
| 放松、信任、别急着走 | 蓝色说「坐」 | 同色系，把椅子搬近 |
| 行动、点击、下决定 | 红色说「冲」 | 冷墙上只钉一颗暖色按钮 |
| 留下来继续逛 | 绿色说「留」 | 铺绿地毯到下一扇门 |
| 感觉值钱、被尊重 | 黑色说「静」 | 关灯，只留金/白，闭嘴 |
| 记住你、忠于你 | 品牌色说「唯一」 | 独占一色上锁，不换季 |

## 5. 说服路径 × 态度

详卡：`persuasion-actions.md`

| 用户在哪 | 动作 | 说服 |
|---|---|---|
| 不知道你是啥（路人） | 打招呼：亮相不报价 | 启发：都在 |
| 好像有点意思（观众） | 带进门：椅子放进门槛 | 启发：你会喜欢 |
| 认真看了（判断者） | 铺材料：摊开后退不催 | 系统：自己看 |
| 我信了（立场者） | 递谈资：一张能进别人口袋的话 | 信任+流畅：告诉别人 |

路人不要铺材料。立场者不要再打招呼。

## 6. 搭配（可前后，不叠一张）

- 路人 + 瞄 + 打招呼
- 观众 + 坐 + 带进门
- 判断者 + 静 + 铺材料
- 立场者 + 唯一 + 递谈资
- 品牌身份问题走坏动作，不走说服四段
