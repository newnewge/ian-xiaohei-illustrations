# Tony 动作总库（下次调用先读这份）

按主题取卡，不要一次全用。一张图只做一个动作。

调用口令：

```
Use $ian-xiaohei-illustrations
按 references/action-library.md 取动作。
主题：{通用 / 公众号 / 品牌 / 颜色 / 说服}
阶段：{路人 / 观众 / 判断者 / 立场者}（可选）
卡号：{G14 / W03 / A01 / C03 / P01}（可选，指定则不再另选）
```

读卡顺序：本页路由 → 对应分卡 → `tony-ip.md` 锁外形 → `prompt-template.md` 生图。

---

## 路由

| 用户在写什么 | 走哪库 | 打开哪份 |
|---|---|---|
| 内容生产、素材、判断、承接、坑 | 通用 | `general-actions.md` |
| 公众号选题、标题、封面、发布、专栏 | 公众号 | `wechat-actions.md` |
| 品牌身份、区隔、空词、承诺、命名 | 品牌坏动作（优先） | `brand-actions.md` |
| 页面要让人停 / 坐 / 冲 / 留 / 静 | 颜色开口 | `color-actions.md` |
| 路人到立场者，怎么说话、下多重的手 | 说服路径 | `persuasion-actions.md` |

品牌身份问题走坏动作，不走说服四段。颜色处理「下一步身体」，品牌处理「你到底是谁」，不要叠一张。

## 3. 品牌坏动作 A01–A13 + B01–B08

## 8. 硬规则

- 每张图一个动作、一个结构、最多 5 个短标注。
- Tony 必须做核心动作，识别件（眼镜 + 格纹）缺一即失形。
- 禁止画回小黑。禁止左上角类型标题。禁止把库画成色环 / 漏斗 / SOP 海报。
- 用户指定卡号时，不要擅自换卡。
