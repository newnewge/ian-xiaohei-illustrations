# 通用动作库（内容生产系统）

Tony 在系统里干活，不是站在流程图旁边讲解。一张图只取一个动作。

## G01 搬运素材
- 画面：Tony 抱着一搬过大的素材砖往工作台搬，砖上写着「原文 / 截图 / 录音」。路上掉了一块「情绪」。
- 标注：搬运 / 素材 / 别掉
- 结构：系统局部

## G02 拉线汇聚信息源
- 画面：三四个分散的信息点，Tony 把细线拧成一股接到工作台。有一根线故意没接上。
- 标注：汇聚 / 这根不接 / 信息源
- 结构：Workflow

## G03 卡在断点里
- 画面：传送带在中段断开。Tony 自己卡在缺口里，一手托住上游素材，一手够不到下游。
- 标注：断点 / 卡着 / 接不上
- 结构：系统局部

## G04 拉动「判断」杆
- 画面：一台简陋分类机。Tony 拉下写着「判断」的杆，一边掉出可用件，一边掉进「先放着」。
- 标注：判断 / 过 / 先放着
- 结构：前后对比

## G05 变成筛选漏斗
- 画面：Tony 把身体弯成漏斗。上面倒进杂料，下面只漏出一小块「能用」。边上有人想把漏斗口撑大，被他按回去。
- 标注：筛选 / 漏下来 / 别撑大
- 结构：概念隐喻

## G06 切开「素材鱼」
- 画面：一条写着「原始素材」的鱼。Tony 按部位切开：流量片、信任片、转化片。刀停在骨头上，不继续剁。
- 标注：一鱼 / 切片 / 骨头留着
- 结构：方法分层

## G07 盖章承接话术
- 画面：工作台上三枚印章：流量 / 信任 / 转化。Tony 只盖一枚，另外两枚扣着。纸上留下一个清楚的印。
- 标注：承接 / 一枚就够 / 话术
- 结构：角色状态

## G08 牵着承接路径
- 画面：一条细绳从文章尾部牵到下一扇门。Tony 走在前面轻轻拉，不拖读者。门上只写下一站名字。
- 标注：下一站 / 牵着 / 不拖
- 结构：地图路线

## G09 举警告牌看坑
- 画面：路上三个浅坑。Tony 举起一块小警告牌对着最像捷径的那个坑，不拦路。
- 标注：这是坑 / 看着像路 / 绕开
- 结构：地图路线

## G10 从洞里伸手但接不住
- 画面：信息井口。Tony 躺在井沿伸手，井底漂着「线索」。手差一截，井壁写着「还没到」。
- 标注：伸手 / 接不住 / 再沉一点
- 结构：角色状态

## G11 搬砖搭桥开门分拣记录
- 画面：四件低科技工具摊开：砖、木板桥、门、分拣筐。Tony 正在用其中一件，其余靠墙。
- 标注：先做这一件 / 别同时
- 结构：方法分层
- 禁止：四件一起开工的流程图

## G12 抱书讲解
- 画面：Tony 抱着一本过厚的方法书，书比人高。他只翻开一页指给读者看，其余页用绳子捆住。
- 标注：就这一页 / 先别全看
- 结构：角色状态

## G13 举指示笔指板
- 画面：白板只写一个结构。Tony 用过长的指示笔点在关键节点上，其余格子空着。
- 标注：看这里 / 其它空着
- 结构：系统局部

## G14 举起识别面板
- 画面：做完之后，Tony 把识别面板举到脸前。面板只有一句验收：「还是不是这件事」。
- 标注：验收 / 还是不是 / 过
- 结构：收束

## 选用

生产过程：G01 G02 G03 G04 G05
加工复用：G06 G07 G08
风险与验收：G09 G10 G14
讲解辅助：G12 G13，不要当主图
G11 只在需要「系统全貌」时用，且只突出正在用的那一件
