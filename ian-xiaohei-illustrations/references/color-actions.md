# 颜色动作库（用户要停 / 靠 / 冲 / 留 / 沉）

用户不是在看配色，是在决定下一步身体做什么。颜色只是那一步的道具。
Tony 脸保持礼貌。坏给「满屏都在喊」的页面看，不给用户看。

一张图只处理一种用户需要。禁止五色排成色环海报。

默认正文配图仍是白底黑线。颜色动作图是例外：色块是主语，Tony 本人保持黑白，格纹仍是他身上唯一纹理。

## 颜色开口（指令层）

颜色自己说话。Tony 只负责把那句话放到对的位置。

| 如果你想让用户…… | 配色动作 | 指令 | 用哪张卡 |
|---|---|---|---|
| 放松、信任、别急着走 | 主色蓝/绿，辅色同色系，中差过渡 | 蓝色说「坐」 | C06 |
| 注意、停一下、往这看 | 冷色背景上放黄色元素 | 黄色说「瞄」 | C01 |
| 行动、点击、下决定 | 唯一高饱和暖色按钮，放在大面积冷色底上 | 红色说「冲」 | C03 |
| 感觉值钱、有分量、被尊重 | 黑/深灰为主，金/白点缀，大留白 | 黑色说「静」 | C05 |
| 记住你、认出你、忠于你 | 独占一个色相，几十年不变 | 品牌色说「唯一」 | C07 |

五句指令不要写进同一张图。品牌色「唯一」和品牌坏动作可以前后出现，不要叠在一张里。

## C01 瞄 · 黄标停眼
- 用户需要：停下来看一眼
- 颜色：黄（瞄）
- 做法：在蓝 / 绿底上放一枚黄标，吸引注意但不压迫
- 画面：冷色墙面。Tony 踏脚把一枚过大的黄标别在路过的视线高度，不挥旗、不喊。墙上原有的红标被他揭掉扔进桶。
- 坏 / 笑：他不是在设计，是在给眼睛做交通指挥，而且只准亮一次
- 标注：瞄一眼 / 黄标 / 别喊
- 禁止：满屏黄、闪烁、大字号尖叫

## C02 靠 · 蓝毯让人坐下读
- 用户需要：安心慢慢读
- 颜色：蓝（靠），辅绿或灰
- 做法：蓝为主，减少刺激
- 画面：Tony 把一条蓝毯子盖在一篇长文上，边上的刺眼红条被他折起来。读者的椅子被他往里挪了半步。
- 坏 / 笑：安全感是被盖上的，不是写在「信任我们」里的
- 标注：靠着读 / 减刺激 / 蓝
- 禁止：科技蓝发光、一排信任徽章

## C03 冲 · 冷墙上只钉一颗暖色按钮
- 用户需要：立刻戳下去
- 颜色：红 / 橙（冲）
- 做法：大面积冷色底，只放一颗暖色按钮
- 画面：整面冷墙。Tony 从一盒按钮里只取出一颗橙红的钉上去，其余全锁进抽屉。他指着那一颗，不解释。
- 坏 / 笑：行动力来自「别的都不给按」
- 标注：戳这里 / 唯一 / 冷底
- 禁止：三个主按钮并列、彩虹 CTA

## C04 留 · 把绿地毯铺到下一间
- 用户需要：留下来继续逛
- 颜色：绿（留）
- 做法：绿为主，配自然质感，增强归属
- 画面：Tony 从门口往里铺一条绿地毯，地毯延伸到下一扇虚掩的门。他没有拉人，只是把路铺好。墙上贴一小块质感样本，不是标语。
- 坏 / 笑：归属感是路，不是「欢迎回来」
- 标注：留下 / 再走两步 / 绿
- 禁止：会员等级金字塔、积分轰炸

## C05 沉 · 关灯只留金/白让人自己品
- 用户需要：相信你花的值
- 颜色：黑 + 金 / 白（沉）
- 做法：黑底 + 留白，让用户自己品出价值
- 画面：Tony 把顶灯拧灭。黑场里只剩一块白卡片或一道金边。他站在旁边不介绍，识别面板朝下。
- 坏 / 笑：价值被说明就会变薄；他选择把嘴闭上
- 标注：自己品 / 留白 / 沉
- 禁止：黑金土豪花纹、价格大字、勋章墙

## C06 坐 · 蓝色把椅子搬近
- 用户需要：放松、信任、别急着走
- 颜色：蓝说「坐」（主色蓝/绿，辅色同色系，中差过渡）
- 做法：整间屋子只走蓝绿邻近色，对比压到中差，不跳
- 画面：Tony 把一把蓝椅子搬到页面前面，轻轻拍拍椅背。墙上没有第二套对比色。出口的箭头被他折小。
- 坏 / 笑：挽留不是拉住袖子，是把走的理由收掉
- 标注：坐 / 别急着走 / 同色系
- 禁止：信任徽章墙、大字「欢迎光临」

## C07 唯一 · 品牌色上锁
- 用户需要：记住你、认出你、忠于你
- 颜色：品牌色说「唯一」
- 做法：独占一个色相，几十年不变
- 画面：Tony 把一管品牌色油漆锁进保险柜，钥匙别在识别面板上。地上是被他收走的其他色管。墙上那一块色只出现一次，不渐变、不换季。
- 坏 / 笑：忠诚来自「不许换」，不是来自「今年流行」
- 标注：唯一 / 上锁 / 不换季
- 禁止：年度主视觉换色、彩虹品牌、渐变包装墙

## 选用

| 用户身体要做的事 | 取色 | 取动作 |
|---|---|---|
| 停一眼 | 黄 | C01 |
| 坐下来读 | 蓝 | C02 |
| 立刻下手 | 红 / 橙 | C03 |
| 再逛一间 | 绿 | C04 |
| 觉得值 / 被尊重 | 黑 + 金 / 白 | C05 静 |
| 别急着走 | 蓝 / 绿同色系 | C06 坐 |
| 记住你 | 独占一色 | C07 唯一 |

和品牌坏动作不要叠在同一张图。颜色动作处理「页面上的下一步」，品牌动作处理「你到底是谁」。
