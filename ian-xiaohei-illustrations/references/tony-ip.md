# Tony IP

基准图：`assets/_my-ip/tony.png` 或仓库根 `_my-ip/tony.png`。生成前先看这张图。

## 角色定义

Tony（东尼 / 邢东尼 · 品牌教练）是本 skill 中文正文配图的固定视觉 IP，替换原小黑。

他不是吉祥物，不是贴纸，不是可爱装饰，而是正在认真参与系统运转的教练/工作者。默认每张图都要出现 Tony。

## 外形（锁死）

从基准图提炼，不可改：

- Q 版大头小人，头身比约 1:1.5 至 1:3，头部约占全身 40%。
- 光头，头顶一道反光高光弧线。
- 圆形黑边眼镜：两个圆环 + 鼻梁连接线（识别件一）。
- 圆点眼 + 细弧线微笑 + 圆形腮红。
- 黑白格纹衬衫：全身唯一纹理（识别件二）；黑裤、黑鞋。
- 细线四肢，平涂无阴影渐变。
- 可手持笔记本或识别面板，但不靠道具辨认。
- 表情温和、认真、带学者式自信；呆而不蠢。

风格关键词：monoline，黑白线稿，Q 版，大头，光头，圆框眼镜，格纹衬衫，细肢，腮红，deadpan，不卖萌。

## 四人组（群像时锁死）

四人共用：圆点眼 + 细笑 + 腮红，黑白 monoline，一人一道具。群像里 Tony 必须占核心动作，其余三人协助，禁止合影站排。

- **九掌柜 · 主教练**：长直黑发齐刘海，黑色长大衣，黑裤。道具：白板。
- **Serena · 商业教练**：女性，中分披发（头发从中间分开自然垂落，不是短发、不是盘发、不是马尾），休闲裙（A 字或直筒裙，不是西装裤）。道具：笔记本电脑 / 商业路径。
- **阿久 · 产品教练**：女性，长发（长过肩，可以微卷但必须是长发），小西装（短款西装外套 + 裙或裤，不是大波浪短发男装）。圆框眼镜。道具：清单板 + 竖拇指。
- **邢东尼 · 品牌教练**：即 Tony。道具：识别面板。

禁止：把 Serena 画成短发男性或盘发职业装；把阿久画成短卷发男性。

## 性格

- 低调的教练 / 系统操作员。
- 很认真，但做的事有点荒诞。
- 亲和、稳、冷幽默，不卖萌。
- 有点笨拙，但不蠢。
- 脸不坏，事可以坏。坏给假品牌、空词、装出来的调性看。

## 品牌教练专属动作（优先，刻意的坏）

完整动作卡见 `references/brand-actions.md`。

主库：把品牌按在镜子上逼问 / 给「我们不一样」翻吊牌 / 给空词举行加冕再当场摔冠 / 让口号当场自己念一遍 / 把承诺当空头支票剪开 / 在品类更衣室里掀门帘 / 给记忆点打一枚摔不掉的耳钉 / 把触点抓来排队认亲 / 开臆取出三句假话 / 抽走那把「什么都能坐」的椅子 / 把伸向脏活的手拍回去 / 让全部名字站成一排指认主犯 / 举起识别面板

增补：给「很有调性」做酒测 / 把抄来的视觉送去走失处 / 当众翻开品牌宝典只剩目录 / 给「深耕多年」查出生证明 / 让个人名和公司名办离婚 / 把「用户第一」夹上测谎仪 / 给爆款滤镜拆线 / 把定价当信号弹点着

禁止退回工坊正确隐喻：焊接、刮漆、音叉、校色温、分层建楼。那些太正经，不像 Tony。

## 禁止

- 不要画回小黑（黑色实心豆状怪物）。
- 不要把 Tony 画成写实老人或儿童卡通。
- 不要加复杂服装、表情包、闪亮眼睛、阴笑反派脸。
- 不要丢圆框眼镜或格纹衬衫（去任一即失形）。
- 不要让 Tony 只是站在角落里看。
- 不要让 Tony 抢走结构表达。
- 不要过度精致、太商业、太圆润。

## 判断标准

- 去掉 Tony，图的核心隐喻还能完全成立 → Tony 太装饰，重写提示词让他成为动作主体。
- Tony 没戴眼镜 / 没穿格纹衬衫 / 变成普通小人 / 变成小黑 → IP 失形，重生成。
- 品牌图第一眼像培训课件，不像当场揭穿 → 隐喻不够坏，换专属动作重画。
