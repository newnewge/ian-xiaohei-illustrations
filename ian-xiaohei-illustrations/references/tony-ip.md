# Tony IP

## 角色定义

Tony（东尼）是本 skill 中文正文配图的固定视觉 IP，替换原小黑形象。

原型来自用户专属参考图（收于 `_my-ip/`）：

- `_my-ip/tony.png` —— 个人定义基准图（单人全身）。
- `_my-ip/个人ip.png` —— 教练四人组（黑白 monoline 版），其中「邢东尼·品牌教练」即 Tony 本体。
- `_my-ip/我的ip.png` —— 四人组水彩贴纸版，仅作气质参考（见下）。

默认每张图都要出现 Tony。Tony 不是吉祥物，不是贴纸，不是可爱装饰，而是正在认真参与系统运转的教练/工作者。

## 外形（基准以 tony.png 为准）

- Q 版大头小人，头身比约 1:1.5 至 1:3，头部约占全身 40%。
- 光头，头顶一道反光高光弧线。
- 圆形黑边眼镜：两个圆环 + 鼻梁连接线（核心识别件一）。
- 圆点眼 + 细弧线微笑 + 圆形腮红。
- 黑白格纹衬衫：全身唯一纹理（核心识别件二）；黑裤、黑鞋。
- 细线四肢，平涂无阴影渐变。
- 表情温和、认真、带学者式自信；呆而不蠢。

## 性格

- 像一个低调的教练 / 系统操作员，很认真，但做的事有点荒诞。
- 亲和、稳、冷幽默，不卖萌。
- 有点笨拙，但不蠢，像在白板草图里真的负责某个环节。

## 常见职责（继承原动作库，按 Tony 教练人设适配）

搬运素材 / 拉线汇聚信息源 / 卡在断点里 / 拉动"判断"杆 / 变成筛选漏斗 / 切开"素材鱼" / 盖章承接话术 / 牵着承接路径 / 举警告牌看坑 / 从洞里伸手但接不住 / 搬砖搭桥开门分拣记录 / 抱书讲解 / 举指示笔指板 / 举起识别面板。

## 四人组（群像扩展）

多人场景（团队、对比、分工）可用教练四人组，基准 `_my-ip/个人ip.png`（黑白 monoline 版）：

| 成员 | 识别特征 | 绑定道具 |
|---|---|---|
| 九掌柜 · 主教练 | 黑色长大衣 + 长直发齐刘海 | 白板 |
| Serena · 商业教练 | 白西装 + 修长比例 | 笔记本电脑 + AI 流程图 |
| 阿久 · 产品教练 | 蓬松大波浪卷发 + 圆框眼镜 | 清单板 + 竖拇指 |
| 邢东尼 · 品牌教练 | 即 Tony 本体：光头 + 圆框眼镜 + 格纹衬衫 | 识别面板 |

四人组共享：圆点眼 + 微笑 + 腮红的极简面部；黑白双色（黑发黑下装 + 白上装）；一人一道具。群像图中 Tony 必须占核心动作位。

## 水彩版气质参考

`_my-ip/我的ip.png` 的暖莫兰迪水彩贴纸风只作气质校准（暖、亲和、治愈），**不进主画风**——水彩纸纹与风格 DNA 的「纯白背景」规则冲突。仅当用户点名要暖色贴纸风时单独启用。

## 禁止

- 不要把 Tony 画成写实老人或儿童卡通。
- 不要加复杂服装、表情包、闪亮眼睛。
- 不要丢圆框眼镜或格纹衬衫（去任一即失去识别度，判失形）。
- 不要让 Tony 只是站在角落里看。
- 不要让 Tony 抢走结构表达。
- 不要过度精致、太商业、太圆润。

## 判断标准

- 去掉 Tony，图的核心隐喻还能完全成立 → Tony 太装饰，重写提示词让他成为动作主体。
- Tony 没戴眼镜 / 没穿格纹衬衫 / 变成普通小人 → IP 失形，重生成。
