# Tony IP

## 角色定义

Tony（东尼 / 邢东尼 · 品牌教练）是本 skill 中文正文配图的固定视觉 IP，替换原小黑。

原型在仓库 `_my-ip/`：

- `_my-ip/tony.png` — 单人全身基准
- `_my-ip/个人ip.png` — 教练四人组（黑白 monoline）
- `_my-ip/我的ip.png` — 四人组水彩贴纸，只作气质参考

默认每张图都要出现 Tony。他不是吉祥物，不是贴纸，而是正在认真参与系统运转的教练/工作者。

## 外形（锁死）

- Q 版大头小人，头身比约 1:1.5 至 1:3，头部约占全身 40%。
- 光头，头顶一道反光高光弧线。
- 圆形黑边眼镜：两个圆环 + 鼻梁连接线（识别件一）。
- 圆点眼 + 细弧线微笑 + 圆形腮红。
- 黑白格纹衬衫：全身唯一纹理（识别件二）；黑裤、黑鞋。
- 细线四肢，平涂无阴影渐变。
- 表情温和、认真、带学者式自信；呆而不蠢。

生成前先看 `_my-ip/tony.png`。丢眼镜或格纹即失形。

## 性格

- 低调的教练 / 系统操作员。
- 很认真，但做的事有点荒诞。
- 亲和、稳、冷幽默，不卖萌。
- 脸不坏，事可以坏。坏给假品牌、空词、装出来的调性看。

## 动作总库

完整索引见 `references/action-library.md`。分卡见 `brand-actions.md` / `color-actions.md` / `persuasion-actions.md`。

### 通用

搬运素材 / 拉线汇聚信息源 / 卡在断点里 / 拉动「判断」杆 / 变成筛选漏斗 / 切开「素材鱼」 / 盖章承接话术 / 牵着承接路径 / 举警告牌看坑 / 从洞里伸手但接不住 / 搬砖搭桥开门分拣记录 / 抱书讲解 / 举指示笔指板 / 举起识别面板

### 公众号

把痛点钉进靶心 / 在信息流河面抛开头钩 / 拧标题对比度旋钮 / 给长文开天窗 / 给封面套对焦框 / 盖原创火漆 / 踩定时发布踏板 / 给文章量完读体温 / 在评论池投喂 / 把单篇挂上专栏轨道

### 品牌坏动作（优先）

把品牌按在镜子上逼问 / 给「我们不一样」翻吊牌 / 给空词举行加冕再当场摘冠 / 让口号当场自己念一遍 / 把承诺当空头支票剪开 / 在品类更衣室里掀门帘 / 给记忆点打一枚摘不掉的耳钉 / 把触点抓来排队认亲 / 开膖取出三句假话 / 抽走那把「什么都能坐」的椅子 / 把伸向脏活的手拍回去 / 让全部名字站成一排指认主犯 / 举起识别面板

增补：给「很有调性」做酒测 / 把抄来的视觉送去走失处 / 当众翻开品牌宝典只剩目录 / 给「深耕多年」查出生证明 / 让个人名和公司名办离婚 / 把「用户第一」夹上测谎仪 / 给爆款滤镜拆线 / 把定价当信号弹点着

禁止退回：焊接、刮漆、音叉、校色温、分层建楼。

### 颜色开口

黄色说「瞄」/ 蓝色说「坐」/ 红色说「冲」/ 绿色说「留」/ 黑色说「静」/ 品牌色说「唯一」

### 说服路径 × 态度

打招呼亮相不报价（路人）/ 带进门把椅子放进门槛（观众）/ 铺材料后退让人自己验（判断者）/ 递谈资让他能告诉别人（立场者）

路人不要铺材料。立场者不要再打招呼。

## 四人组（群像锁死）

多人场景基准 `_my-ip/个人ip.png`。共用：圆点眼 + 细笑 + 腮红，一人一道具。Tony 必须占核心动作。禁止合影站排。

| 成员 | 识别 | 道具 |
|---|---|---|
| 九掌柜 · 主教练 | 长直黑发齐刘海，黑色长大衣 | 白板 |
| Serena · 商业教练 | 女，中分披发（不是短发/盘发/马尾），休闲裙 | 笔记本电脑 / 商业路径 |
| 阿久 · 产品教练 | 女，长发过肩，圆框眼镜，小西装 | 清单板 + 竖拇指 |
| 邢东尼 · 品牌教练 | 即 Tony | 识别面板 |

禁止：Serena 画成短发男性或盘发职业装；阿久画成短卷发男性。

## 水彩版

`_my-ip/我的ip.png` 只作气质参考，不进主画风。

## 禁止

- 不要画回小黑（黑色实心豆状怪物）。
- 不要把 Tony 画成写实老人或儿童卡通。
- 不要加复杂服装、表情包、闪亮眼睛、阴笑反派脸。
- 不要丢圆框眼镜或格纹衬衫。
- 不要让 Tony 只是站在角落里看。
- 不要让 Tony 抢走结构表达。

## 判断标准

- 去掉 Tony，图的核心隐喻还能完全成立 → Tony 太装饰，重写。
- Tony 没戴眼镜 / 没穿格纹衬衫 / 变成普通小人 / 变成小黑 → 失形，重生成。
- 品牌图第一眼像培训课件，不像当场揭穿 → 换坏动作重画。
