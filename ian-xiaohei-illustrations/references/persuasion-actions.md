# 说服动作库（路径 × 态度）

用户站在哪一段，决定 Tony 下手的力度。不要对路人铺材料，不要对立场者还在打招呼。

一张图只处理一个阶段。禁止把四段画成漏斗海报。

Tony 脸保持礼貌。坏给「见面就报价」和「证据堆成墙还不让人走」看。

## 动作地图

| 用户在哪 | Tony 做什么 | 用什么说服 | 卡 |
|---|---|---|---|
| 「不知道你是啥」（路人） | 打招呼：亮个相，别急着卖 | 启发：稀缺 / 社会认同 / 权威——「你看，大家都在」 | P01 |
| 「好像有点意思」（观众） | 带进门：给个理由留下来 | 启发：喜好 / 情绪——「你也会喜欢这个」 | P02 |
| 「认真看了」（判断者） | 铺材料：证据摆开，让他自己验 | 系统：规格 / 数据 / USP / 对比——「你自己看，我不催」 | P03 |
| 「我信了」（立场者） | 递谈资：给他能拿出去说的话 | 信任 + 流畅——「你已经信了，现在可以告诉别人」 | P04 |

## P01 打招呼 · 亮相不报价
- 用户：路人，还不知道你是啥
- 画面：门口。Tony 举起识别面板当脸，面板上只有名字/轮廓。报价单被他踩在脚边或折进后袋。门外一小簇人影，他只点一下下巴：都在。不拉人进门。
- 坏 / 笑：最想说的那句被他咽回去了
- 标注：打招呼 / 别卖 / 都在
- 禁止：大字卖点、价格、三特征并列

## P02 带进门 · 椅子放在门槛里
- 用户：观众，好像有点意思
- 画面：Tony 侧身顶住门，门槛内侧放一把椅子和一杯水。他不拉袖子。门外的黄标还亮着，门内已经换成可坐的蓝。
- 坏 / 笑：挽留是把椅子放进去，不是把人拖进去
- 标注：带进门 / 留下 / 你会喜欢
- 禁止：欢迎光临横幅、会员扫码墙

## P03 铺材料 · 证据摊开人退后
- 用户：判断者，认真看了
- 画面：长桌。Tony 把规格、数据、对比、USP 四叠纸摊平，自己往后退一步，双手背后。桌上没有倒计时、没有「立即购买」。
- 坏 / 笑：催转化的手被他反绑了
- 标注：自己看 / 不催 / 材料
- 禁止：红章限时、假对比、堆到看不清

## P04 递谈资 · 把话塞进口袋
- 用户：立场者，我信了
- 画面：Tony 把一张对折小卡片递过去，卡片短到能装进别人口袋。卡片上只有一句能带出门的话。他不再解释产品。
- 坏 / 笑：说服在这一步结束，变成传话
- 标注：谈资 / 告诉别人 / 带走
- 禁止：继续讲功能、再塞一本手册

## 选用

路人只用 P01。观众从 P01 走到 P02。判断者才允许 P03。P04 只给已经信的人。

和颜色指令可前后搭配，不叠一张图：
- 路人 + 黄色说「瞄」
- 观众 + 蓝色说「坐」
- 判断者 + 黑色说「静」
- 立场者 + 品牌色说「唯一」
