# 品牌教练动作库（刻意的坏）

有趣、失禁的笑、刻意的坏。Tony 脸保持礼貌，下手对空词和假定位不客气。
坏给词、吊牌、支票、椅子、门帘看，不丑化客户身体。禁止退回焊接、刮漆、音叉、校色温、建楼。

每张图只取一个动作。正文里最多 3 个坏动作 + 收束面板。

## A. 核心 13 组（主库）

### A01 把品牌按在镜子上逼问
- 真工作：定位前的身份确认
- 画面：Tony 抓着一个无脸品牌剪影的后领，把它按在立镜上。镜面呵出「你到底是谁」。识别面板贴在镜角。
- 坏 / 笑：最怕的第一句被按住问；力度过大，礼仪还在
- 标注：你到底是谁 / 答不出 / 别逃
- 结构：概念隐喻

### A02 给「我们不一样」翻吊牌
- 真工作：区隔检验
- 画面：衣服前胸绣「我们不一样」。Tony 翻到后领，吊牌货号与竞品同款。他举吊牌给观众看。
- 坏 / 笑：口号在正面，真相在吊牌；庄严句被质检
- 标注：我们不一样 / 同款货号 / 翻过来
- 结构：前后对比

### A03 给空词举行加冕再当场摔冠
- 真工作：清词
- 画面：纸皇冠扣在「赋能」头上三秒，Tony 摔下扔进桶。空词瘦成一张皮。旁边还排着「闭环」「一站式」。
- 坏 / 笑：先配合仪式，再当众拆台
- 标注：赋能 / 加冕 / 摔掉
- 结构：小漫画分镜或单动作

### A04 让口号当场自己念一遍
- 真工作：口号 / 口头介绍
- 画面：Tony 捏着一张会卷边的口号纸，逼它出声。纸念到一半自己卷起来想逃，被按平。
- 坏 / 笑：连纸都念不下去
- 标注：出声 / 卡壳 / 删掉
- 结构：角色状态

### A05 把承诺当空头支票剪开
- 真工作：承诺 vs 交付
- 画面：过大支票收款人「用户」。Tony 从中剪开，掉出欠条：周期、范围、售后。欠条夹进识别面板。
- 坏 / 笑：愿景按金融诈骗处理
- 标注：承诺 / 空头 / 欠条
- 结构：概念隐喻

### A06 在品类更衣室里掀门帘
- 真工作：品类伪装
- 画面：一排门帘写咨询 / 培训 / 陪跑。Tony 掀开一帘，里面有人在换别家队服。识别面板伸进去当遮羞布。
- 坏 / 笑：不是定位错，是在别人隔间换衣服
- 标注：占用 / 换装 / 出去
- 结构：系统局部

### A07 给记忆点打一枚摔不掉的耳钉
- 真工作：识别资产
- 画面：Tony 把过大耳钉（色块 / 句式 / 格纹）打进品牌侧脸，背面拧死。地上是一盒「本季主视觉」耳夹。
- 坏 / 笑：换视觉变成拆肉
- 标注：摔不掉 / 耳夹会掉 / 重复
- 结构：概念隐喻

### A08 把触点抓来排队认亲
- 真工作：跨触点一致性
- 画面：海报、报价单、朋友圈、前台站成一列。Tony 用识别面板当鉴定书，指着不像的那张报价单。报价单低头。
- 坏 / 笑：最不像的往往是最赚钱的那张纸
- 标注：认亲 / 不像 / 报价单
- 结构：角色状态

### A09 开臆取出三句假话
- 真工作：信息审计
- 画面：说明书被礼貌剖开（示意性切开，不画 gore）。Tony 用夹子取出「我们重视 / 深耕多年 / 只为更好」，托盘写「不可食用」。
- 坏 / 笑：手术很认真，取出的东西轻得可笑
- 标注：不可食用 / 假话 / 还剩什么
- 结构：概念隐喻

### A10 抽走那把「什么都能坐」的椅子
- 真工作：定位即放弃
- 画面：全能办公椅。Tony 微笑抽走，坐着的品牌顿住，只好去坐写着具体对象的窄决。大椅子被锁进储藏室。
- 坏 / 笑：礼貌的暗算
- 标注：全能 / 抽走 / 只坐这个
- 结构：前后对比

### A11 把伸向脏活的手拍回去
- 真工作：品牌禁区
- 画面：一只手伸向「立刻起量」按钮。Tony 用识别面板抽手背一下，留下格纹印。他点头，手续完成。
- 坏 / 笑：体罚很轻，仪式感很重
- 标注：禁区 / 一下 / 不接
- 结构：概念隐喻

### A12 让全部名字站成一排指认主犯
- 真工作：品牌架构
- 画面：人名、公司名、产品名、栏目名举号牌。Tony 当指认官，面板指向一个：「对外只许它说话。」其余按下去。
- 坏 / 笑：内部命名变成刑侦
- 标注：主犯 / 对外 / 改口
- 结构：角色状态

### A13 举起识别面板
- 真工作：验收
- 画面：前面坏完之后，Tony 把识别面板举到脸前。面板上只有「还能被认出吗」。周围是收拾干净的现场。
- 坏 / 笑：结案陈词，不是宣传物料
- 标注：认出 / 验收 / 过没过
- 结构：收束

## B. 增补 8 组（丰富用）

### B01 给「很有调性」做酒测
吹气筒塞进「调性」嘴里。指针停在「醉了 / 只是形容词」。Tony 记录单，不评价。
标注：酒测 / 调性 / 醒着吗

### B02 把抄来的视觉送去走失处
Tony 把一叠眼熟的封面按在「走失登记」窗台上，窗口里探出竞品的眼睛。登记表写「捡到类似一张」。
标注：走失 / 眼熟 / 领回

### B03 当众翻开品牌宝典只剩目录
过厚的「品牌宝典」被 Tony 翻开，里面全是空白，只印着目录。他举给观众看最后一页的页码。
标注：宝典 / 空白 / 目录

### B04 给「深耕多年」查出生证明
「深耕多年」站上户籍窗口。Tony 盖章的出生证明日期是上个月。红字「未成年」。
标注：深耕 / 出生证 / 上个月

### B05 让个人名和公司名办离婚
两本户口本，Tony 当民政员盖「离婚」，中间一条线把创始人名和公司名分开。双方抢孩子「项目名」。
标注：离婚 / 人名 / 公司名

### B06 把「用户第一」夹上测谎仪
「用户第一」坐着，手臂夹着测谎仪。Tony 问「那定价为什么这么写」，指针狂跳。
标注：测谎 / 用户第一 / 跳了

### B07 给爆款滤镜拆线
品牌脸上贴着「爆款」整容贴。Tony 拆线，底下露出普通的交付脸。地上是掉下来的滤镜片。
标注：拆线 / 爆款 / 原脸

### B08 把定价当信号弹点着
Tony 点燃一枚写着价格的信号弹。该亮「贵得有理由」时，弹却写成「随便砍」。烟往错误方向飘。
标注：信号 / 定价 / 飘偏
