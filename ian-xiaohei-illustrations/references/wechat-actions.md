# 公众号动作库（指示性 + 隐喻性）

对接公众号生产，不是后台截图。一张图只取一个动作。

## W01 把痛点钉进靶心
- 真工作：选题对准真实痛点
- 画面：一块靶。Tony 把一枚过大的钉子钉进红心，周围一圈「热点」飞镶全钉在外环。
- 标注：痛点 / 钉死 / 外环是热闹
- 结构：概念隐喻

## W02 在信息流河面抛开头钩
- 真工作：开头留人
- 画面：信息流是一条河。Tony 站在岸边抛出一只开口钩，钩上只有半句话。河里漂过完整长文，没人咬。
- 标注：开头 / 半句 / 咬钩
- 结构：概念隐喻

## W03 拧标题对比度旋钮
- 真工作：标题信息差
- 画面：一台老旋钮。Tony 把「对比度」拧过一格，标题两边出现「以为 / 其实」。拧到底的那档写着「标题党」，被他锁住。
- 标注：对比度 / 一格就够 / 锁死
- 结构：前后对比

## W04 给长文开天窗
- 真工作：中段换气、降低劝退
- 画面：一篇过长的字墙。Tony 在中段挖开一扇小天窗，光只照到一句判断。他没有把整面墙拆掉。
- 标注：天窗 / 换气 / 留着读
- 结构：系统局部

## W05 给封面套对焦框
- 真工作：封面只服务一个记忆点
- 画面：Tony 把一个取景框套在封面上，框外的装饰被他剪掉。框里只剩一个可被认出的符号。
- 标注：对焦 / 框外剪掉 / 认出
- 结构：前后对比

## W06 盖原创火漆
- 真工作：辨认作者、防稀释
- 画面：信封口。Tony 盖下一枚火漆，印的是识别符号不是「原创」两个字。旁边一叠无印件被他推开。
- 标注：火漆 / 是我的 / 无印推开
- 结构：角色状态

## W07 踩定时发布踏板
- 真工作：发布时间作为动作，不是焦虑
- 画面：Tony 踩下一只落地踏板，时钟只亮一个时刻。其它时刻的灯被他用布盖上。
- 标注：就这个点 / 其它盖上
- 结构：角色状态

## W08 给文章量完读体温
- 真工作：看完读，不看虚荣数据
- 画面：Tony 把温度计夹在一篇文章腋下。读数写「读完了 / 只翻了标题」。点赞心形在桌上没被量。
- 标注：体温 / 读完了吗 / 别量赞
- 结构：概念隐喻

## W09 在评论池投喂
- 真工作：评论区经营，不是刷屏
- 画面：浅水池。Tony 一次只丢一颗小食，池里几条读者鱼围过来。他手里还握着一把，没有全倒。
- 标注：投一颗 / 别倒光 / 评论
- 结构：角色状态

## W10 把单篇挂上专栏轨道
- 真工作：单篇进入连续栏目，而不是孤篇爆款
- 画面：一条空中轨道。Tony 把单篇挂上车钩，轨道通向写着栏目名的下一站。孤篇奖杯留在站台没上车。
- 标注：挂上轨道 / 下一站 / 孤篇留下
- 结构：地图路线

## 选用

选题开头：W01 W02 W03
成稿呈现：W04 W05 W06
发布与复盘：W07 W08 W09 W10
一篇公众号文最多 2 个公众号动作 + 1 个通用或品牌动作，不要画成运营 SOP 海报。
